# 屏幕翻译处理链设计

本次调研以公开源代码为依据，检查识别、翻译与排版之间的数据边界，不以项目排名或宣传说明作为质量结论。调研日期为 2026-10-25。

## 实现参考

| 项目与源代码 | 可核查的设计 | 本项目采用的原则 |
| --- | --- | --- |
| [Translumo](https://github.com/ramjke/Translumo/blob/master/src/Translumo.Processing/TranslationProcessingService.cs) | 先运行主要 OCR，必要时比较其他引擎的结果评分，再提交识别文字 | 先执行低成本识别；结果不足时比较其他本地识别器 |
| [LunaTranslator](https://github.com/HIllya51/LunaTranslator/blob/main/src/LunaTranslator/gui/ocrtranslationoverlay.py) | 保存截图版本、文字块编号与位置，拒绝过期结果 | 文字、位置与任务身份分别维护；继续使用既有任务取消及世代检查 |
| [STranslate](https://github.com/STranslate/STranslate/blob/main/src/STranslate/ViewModels/ImageTranslateWindowViewModel.cs) | OCR 文字块进入独立翻译服务，覆盖文档保存文字与布局 | OCR 模式让模型仅翻译文字；排版由本地模块负责 |

上述项目并非全部支持无条件自动识别语言。Translumo 的多引擎评分也不等同于本项目的语言选择算法。本项目仅参考职责分离及按需比较的设计，没有引入这些项目的实现代码或运行时。

## 处理边界

OCR 模式依次执行文字检测、本地识别、文字翻译、译文检查和排版。检测只执行一次，文字行坐标始终由本地保存。自动模式先运行英语识别器；当综合得分或单行得分不足时，比较日语、韩语识别结果，逐行保留较优候选。评分结合字符置信度与文字对检测区域的覆盖程度，避免将大片日文识别成少量高置信度拉丁字符。识别器按顺序加载，避免同时驻留全部模型。

后续识别器仅处理得分低于 0.90 的文字行，复用其余已识别结果；`ocr_recognize.recognized_lines` 记录实际重新识别的行数。该优化减少图标与装饰性小字对整页延迟的影响，仍受候选评分误判的限制。

自动识别当前仅覆盖内置的英语、日语、韩语识别器。不同识别器的置信度不保证完全可比，因此这是一种候选选择策略，不构成识别正确性的证明。低置信度仍须提示，手动选择语言继续保留。模型加载、识别耗时及实际识别器编号进入诊断日志。

AI 模式直接提交选区图片，不运行本地 OCR。模型返回的译文与位置分别校验。位置不可用时保留全文阅读；对于小型、单段、多行截图，本地像素分析可以校正误报为单行的范围。像素分析不识别字符、不调用识别模型，也不增加网络请求。复杂背景或多段内容不适用该单段校正。

视觉请求从实际上传的 JPEG 头部读取宽高，提示词及 JSON Schema 均以该图片的像素为坐标单位。兼容接口、Gemini 和 Anthropic 的响应使用同一坐标范围解析，再转换为内部坐标映射至原始截图。原图、上传图和屏幕坐标的缩放由程序完成，模型无需执行 0–1000 归一化。旧离线响应继续按原有归一化协议解析。

有效的模型坐标直接用于贴片，不因像素分析未找到文字、局部溢出或其他片段异常而取消整页覆盖。普通多片段布局不再根据邻域像素移动贴片原点；像素扫描不构成第二次文字识别。缺失或完全越界的坐标逐项保留到全文阅读。该流程保留模型的位置估计误差，不把贴片可见视为位置准确的证明。

译文检查独立于 JSON 解析。错误对话框和日志中的自然语言需要翻译，类名、API 名称及代码标识符可以保留。明显未翻译的英文句子或原样返回的日、韩文段落被标记为未翻译，不覆盖原图，也不进入已完成翻译上下文。该检查不验证语义等价或全部漏译情况，不触发额外请求。

## 验证依据

真实回归输入保存于 `tests/fixtures/user/`：日文游戏更新对话框、英文握手错误、英文网页、日文新闻及用户提供的视觉响应。离屏渲染检查最终文字范围；OCR 检查识别文字中的关键内容；协议测试检查仅文字请求、编号完整性、取消及超时边界。合成样本仅用于隔离协议和算法条件。

英文报错的实际视觉响应将三行原文定位成一行；该响应固定为回归样本。GitHub 整页的旧归一化响应存在多个错位，现作为不得触发整页覆盖取消的回归样本。新的像素坐标响应返回 52 段，用于离屏检查；实际渲染仍需检查字体、原文残留与模型定位偏差。请求完成时间与 JSON 合法性不能证明原位翻译正确。

截图、服务响应正文与原文译文不写入日常诊断日志。手动诊断工具仅在明确指定结果文件时保存供离屏重放的结果，交付包不包含这些测试材料。
