# 你给我翻译翻译什么叫翻译

Windows 屏幕与文本翻译工具，提供区域截图翻译、连续翻页翻译与文本会话翻译。适用于文章网页阅读、表格文档、游戏定帧界面与漫画等场景。

## 功能

### 截图翻译

框选屏幕区域后，由本地引擎识别原文文字与排版形态，按段落或对话分组送入所选模型翻译，并在原位覆盖显示译文。

- **排版自适应**：横排页面与竖排漫画自动分组并统一同段或同气泡字号，竖排内容沿原列位置逐列排布；原位覆盖时自动避让并保留表格边框、分隔线与下划线等结构线。
- **原文语言**：提供自动识别（本地）、英语、日语与韩语四项；本地识别未取到文字时，具备视觉能力的模型直接读取整张截图翻译。
- **单次与复用**：支持 **框选翻译** 与 **翻译上次区域**，并在原位译文工具条中切换 **原位译文**、**查看原图**、**全文阅读** 与 **AI识图翻译**，以及复制译文或重新框选。

### 连续翻译

适合阅读漫画、电子书、文档或翻页类画面。框选一次区域并进入连续模式后：

- **鼠标穿透**：译文叠层不拦截鼠标事件，可直接点击下层窗口进行翻页或交互。
- **自动重译**：在下层画面点击或监测到选区画面变化时自动隐藏旧译文，待画面恢复稳定后重新捕获并翻译。
- **状态浮条**：翻页等待与重译期间在区域附近显示当前状态（等待翻页、检测到画面变化等），按 `Esc`、点击译文工具条 **关闭** 或状态浮条关闭按钮退出连续翻译。

### 文本翻译

支持输入文字、粘贴图片或拖入图片文件后发送，按所选目标语言返回译文。每次最多附加 4 张图片，单张图片上限 20 MB（多帧图片读取第一帧）。会话支持复制、停止、重试与清空。

### 模型连接

支持 OpenAI Compatible、DeepSeek、OpenAI、通义千问、豆包、Kimi、GLM、硅基流动、Gemini 与 Claude 等通用模型服务，以及 DeepL、Azure Translator 与 Qwen-MT 专用翻译接口。文本翻译与截图翻译共用当前连接配置，各服务参数分别保存。

## 运行条件

- Windows 10 1809 及以上 x64 系统
- 网络连接与用户自备的 API 密钥
- 本地识别组件随程序附带，无需额外安装 Python、CUDA 或 GPU 运行环境

通用模型服务中涉及图片输入（文本贴图或「AI识图翻译」）时，要求所选模型具备视觉识别能力；选择 DeepL、Azure Translator 或 Qwen-MT 等纯文本协议时，截图翻译以本地识别出的文字请求调用。

从 [GitHub Releases](https://github.com/DS-BigMountain/ScreenAITranslator/releases/latest) 下载安装包或便携包。便携版完整解压后运行 `你给我翻译翻译什么叫翻译.exe`，程序需与附带的运行时、图标、`models` 目录及许可证文件共同使用。

## 使用方法

1. **配置连接**：进入 **设置 → 模型连接**，选择服务提供方并填写 API 地址、密钥与模型名称（Azure 另需填写服务区域）。可点击 **获取模型列表** 或 **测试 API** 验证连通性。
2. **快捷键与常规设置**：在 **设置 → 常规** 中可配置后台开机启动、系统托盘图标显示，以及 **框选翻译**、**连续翻译**、**翻译上次区域** 与 **打开设置** 四项全局快捷键；在「翻译偏好」中可配置最近上下文条数与截图翻译附加要求。
3. **文本翻译**：在 **文本翻译** 页选择目标语言，输入文本或添加图片后发送。默认 `Enter` 发送、`Shift+Enter` 换行，可在设置中改为 `Ctrl+Enter` 发送。
4. **单次截图翻译**：在 **截图翻译** 页选择原文语言，点击 **框选翻译** 或触发对应快捷键框选区域（按 `Esc` 或右键取消框选）；**翻译上次区域** 复用上一次框选位置。完成后可通过底部工具条切换 **原位译文**、**查看原图**、**全文阅读** 或发起单次 **AI识图翻译**，按 `Esc` 或点击 **关闭** 退出视图。
5. **连续翻译**：点击 **连续翻译** 或按连续翻译快捷键框选目标阅读区域，即可直接点击页面翻页并等待自动刷新译文；按 `Esc`、点击工具条 **关闭** 或状态浮条关闭按钮结束连续模式。
6. **外观调整**：在 **截图翻译** 页通过 **译文字体与颜色** 与 **描边与背景** 修改字体、自动/固定字号、文字颜色匹配、描边样式宽度及背景不透明度。
7. **耗时与日志**：在 **截图翻译** 页开启 **导出日志** 后，可通过托盘菜单 **导出日志** 打开日志目录查看各阶段耗时与请求记录。

## 数据与隐私

配置保存在 `%LOCALAPPDATA%\ScreenAITranslator`，API 密钥由 Windows 用户凭据保护。网络支持系统代理、直连与自定义 HTTP 代理，高级设置提供请求时限与自定义 JSON 请求参数。

文本会话与截图上下文仅在内存中保存，程序退出后清除；上一次框选坐标仅在本次运行会话内保留。基础诊断仅记录阶段耗时且不写入密钥；仅当开启 **导出日志** 时，单次截图与请求正文会写入对应追踪目录。
