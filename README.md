# 你给我翻译翻译什么叫翻译

Windows 翻译工具，提供屏幕区域翻译与文本会话翻译。适用于屏幕部分区域截图翻译、游戏定帧页面、漫画等场景。

## 功能

### 屏幕截图翻译

框选区域后由本地识别读出原文文字，按段落送回所选服务翻译，输出简体中文，并在对应位置显示译文。识别按页面形态自适应：横排页面使用通用引擎，竖排与漫画页面切换到漫画专用引擎，竖排对话的译文沿原列位置逐列排布。

原文语言提供自动识别（本地）、英语、日语与韩语四项。本地识别未取到文字时，支持图片的模型改为直接读取整张截图。

### 文本翻译

输入文字、粘贴图片或拖入文件后发送，按所选目标语言返回纯文本译文。每次最多添加四张图片，单张文件上限 20 MB，多帧图片读取第一帧。回复支持复制、停止、重试与清空会话。

### 模型连接

支持 OpenAI Compatible、DeepSeek、OpenAI、通义千问、豆包、Kimi、GLM、硅基流动、Gemini 与 Claude 等通用模型服务，也支持 DeepL、Azure Translator 与 Qwen-MT 专用翻译协议。文本翻译与截图翻译共用同一个连接，各服务分别保存配置。

## 运行条件

- Windows 10 1809 及以上 x64 系统
- 网络连接与用户自备的 API 密钥
- 本地识别随程序附带，无需安装 Python、CUDA 或 GPU 运行环境

通用模型服务用于翻译，其中图片输入要求模型具备视觉识别能力；选择 DeepL、Azure Translator 或 Qwen-MT 时，界面标注「仅支持文字」，截图翻译以文字请求调用。

从 [GitHub Releases](https://github.com/DS-BigMountain/ScreenAITranslator/releases/latest) 下载安装包或便携包。便携版完整解压后运行 `你给我翻译翻译什么叫翻译.exe`，程序需与附带的运行时、图标、`models` 目录及许可证文件共同使用。

## 使用方法

1. **配置连接**：打开 **设置 → 模型连接**，选择服务提供方并填写 API 地址、密钥与模型名称，Azure 资源另需填写服务区域。可点击 **获取模型列表** 载入可用模型，或点击 **测试 API** 用内置样本验证连接，测试过程可能产生计费请求。
2. **文本翻译**：选择目标语言，输入文字或添加图片后发送。默认 Enter 翻译、Shift+Enter 换行，可在设置中改为 Ctrl+Enter。
3. **截图翻译**：选择原文语言与截图分辨率，点击 **框选翻译** 或使用快捷键框选区域；**翻译上次区域** 复用上一次的框选范围。框选时按 Esc 或右键取消。
4. **查看译文**：工具条可在原位译文、查看原图与全文阅读之间切换，并支持 AI识别翻译、复制译文、重新框选与关闭。按 Esc 或点击 **关闭** 退出查看。
5. **调整显示**：在 **截图翻译** 页展开「译文字体与颜色」修改字体、字号与颜色，展开「描边与背景」调整描边与不透明度；关闭「自动匹配原文字号」后可指定固定字号。
6. **排查耗时**：在截图翻译页开启 **导出日志**，完成后通过托盘菜单 **导出日志** 查看各阶段用时与请求内容。

## 数据与隐私

配置保存在 `%LOCALAPPDATA%\ScreenAITranslator`，API 密钥由 Windows 用户凭据保护。网络支持系统代理、直连与自定义 HTTP 代理；高级设置提供请求时限与 JSON 请求参数。

文本会话与截图上下文分别在内存中管理，退出程序后清除；上次框选区域仅在本次运行中保留。诊断日志只记录阶段与耗时，API 密钥不写入任何日志；开启 **导出日志** 后，截图与原文译文保存在对应的追踪目录中。
