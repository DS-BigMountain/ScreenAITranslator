# 屏幕翻译 · Screen AI Translator

**简体中文** | [English](README.en.md)

Windows 原生屏幕翻译工具。框选屏幕区域后，程序识别原文位置并调用用户配置的模型生成译文，在原位置覆盖显示。用户手动选择 OCR 文字翻译或 AI 识图翻译，两种模式不自动切换。设置界面采用 WinUI 3，截图和透明覆盖层采用 Win32 / Direct2D。

## 主要功能

- **框选翻译**：拖动选择屏幕区域，松手后在框内固定所选画面，并显示翻译状态，直至译文显示；处理期间可以取消。
- **原位覆盖**：依据文字行和段落位置排版，自动估算字号并匹配原文主文字颜色。
- **多种阅读方式**：在原位译文、原始截图和全文阅读之间切换，支持复制译文；切换视图无需再次请求模型。
- **拖动重译**：拖动译文框边缘调整位置，松手后截取新区域并翻译。
- **翻译上次区域**：复用本次运行最后一次提交的选区，适用于固定位置的字幕、对话框和页面内容。
- **显示与操作设置**：支持常用字体下拉选择、自定义已安装字体、固定或自动字号、手动文字颜色、背景透明度、自动隐藏及自定义快捷键。

## 运行条件与下载

适用于 Windows 10 1809 及以上版本的 x64 系统。翻译需要网络连接和用户提供的 API Key。通用大模型需支持本程序的 JSON 返回协议；专用翻译服务使用各自的原生协议。AI 识图翻译需要支持图片输入的模型；OCR 文字翻译可使用文字模型或专用翻译服务。

从 [GitHub Releases](https://github.com/DS-BigMountain/ScreenAITranslator/releases/latest) 下载安装包或便携包。安装版提供简体中文安装向导；便携版完整解压后运行 `ScreenAITranslator.exe`。

资源包包含 WinUI 3 运行时、ONNX Runtime、本地 OCR 模型、图标文件及第三方许可证，不需要另外安装 Python、PaddlePaddle 或 GPU 环境。程序必须与配套运行时、图标文件及 `models` 目录共同使用，不能只复制主程序 EXE。

## 使用流程

1. 打开 **模型连接**，选择服务，填写 API 地址、密钥和账号可用的模型名或部署 ID。模型名可以手动输入，也可以获取列表；DeepL 和 Azure Translator 无需选择模型。同一服务切换模型保留密钥；不同服务分别保存连接配置，切回时恢复地址、模型和密钥。首次选择未配置服务时，其密钥为空。主连接和视觉连接分别管理，点击保存设置后写入磁盘；未保存即关闭窗口会放弃本次修改。
2. 在 **翻译与偏好** 中选择翻译模式。OCR 模式另选原文语言；AI 模式按需配置独立视觉连接。点击 **测试连接**，仅验证当前模式使用的连接与输入类型。自检使用内置小样本，不上传桌面截图，可能产生计费请求；模型列表不保证视觉能力。
3. 保存设置，在 **翻译与偏好** 中点击 **框选翻译**，或使用自行设置的快捷键。
4. 拖动框选，松开鼠标开始翻译。Esc 或右键取消框选；处理期间点击状态框的 × 取消。
5. 使用选区旁的工具条切换 **原位译文 / 查看原图 / 全文阅读**，或执行 **复制译文 / 重新框选 / 关闭**。

## 翻译模式

在 **翻译与偏好 → 翻译模式** 中选择，两种模式均输出中文。也可右键托盘图标，通过 **识别方法** 子菜单切换；当前模式以选中标记显示，选择后自动保存并对下次翻译生效。

| 模式 | 本地处理 | 提交给模型的内容 |
| --- | --- | --- |
| OCR 文字翻译 | 使用内置 OCR 检测位置并识别文字 | 仅识别文字及区域编号，不上传截图或坐标；模型只返回译文 |
| AI 识图翻译 | 不运行本地 OCR | 整张选区图片，由模型识别、翻译并返回原文位置 |

OCR 模式支持英语、日语和韩语，无需系统语言包。可选择 **自动识别（本地）**，按需比较内置识别器；手动指定语言可减少比较耗时。低置信度文字仍交给模型翻译，不自动改用图片；工具条提示未识别行数及低置信度区域数量。没有获得可翻译文字时停止并提示，可手动切换 AI 模式。OCR 未检出的文字无法通过文字请求恢复，识别置信度也不等同于准确率。

AI 模式不提交本地文字框或 OCR 结果，适合由视觉模型直接识别的内容。图片分辨率可选择 1280、1600 或 2200 px。模型返回的位置用于原位覆盖，位置及文字识别效果取决于模型；可通过全文阅读查看译文。

AI 模式分别处理译文和位置。与截图相交的文字框在本地裁切；缺失、完全越界或无效的位置不用于原位覆盖，译文保留在全文阅读中。全部位置不可用时自动打开全文阅读。模型未提供译文时，全文阅读保留原文并明确标记；空或无效片段数量显示在状态中。外层 JSON 代码块可在本地解析，不增加请求。

AI 模式明确向模型提供上传图片的像素宽高，要求返回像素坐标，再按截图尺寸映射贴片。部分片段异常或译文溢出不会取消其他贴片；无法定位的片段仍可通过全文阅读查看。模型位置估计仍可能偏移，程序不保证逐项精确覆盖。

两种模式均检查明显未翻译的外文段落，异常结果保留原文并标记，不覆盖原图。位置全部不可用或译文全部异常时自动显示全文阅读。该检查不能替代语义质量判断。

返回内容无法解析时直接报告具体格式错误，不自动重复整图翻译；已知接口不支持严格 JSON 格式时，可调整格式后重新请求。OCR 模式的缺失编号补译独立于此处理。

OCR 模式始终使用主连接。AI 模式默认使用主连接；启用 **AI 识图翻译使用独立连接** 后使用对应的模型与密钥。连接自检随当前模式执行。完成状态显示所选模式、OCR 耗时、API 耗时、请求次数及总处理时间；API 耗时包含网络传输、模型响应、解析及重试。

OCR 按次加载模型，检测与识别分阶段使用内存，处理结束后释放模型会话。设置窗口、选区及译文关闭且后台任务结束约 5 秒后，程序通过后台进程交接释放运行时，保留托盘、快捷键、上次选区及未过期上下文。交接失败时保留原进程；隐藏但未关闭的设置窗口保留草稿，不进入该流程。

## 服务连接与网络

| 服务 | 接入方式 | 配置要点 |
| --- | --- | --- |
| DeepSeek、OpenAI、自定义 OpenAI Compatible | Chat Completions | 填写账号可用的模型名称；视觉能力取决于具体模型 |
| 阿里云百炼、火山方舟、Moonshot、智谱、硅基流动 | 各平台兼容接口 | 预设官方地址；部署型接口需填写部署 ID；区域地址可自行调整 |
| Google Gemini | 原生 generateContent | 使用 Gemini API 密钥和模型名称 |
| Anthropic Claude | 原生 Messages | 使用 Anthropic API 密钥和模型名称 |
| DeepL | 原生文本翻译 | Free 默认使用 `https://api-free.deepl.com/v2`；Pro 使用 `https://api.deepl.com/v2` |
| Microsoft Azure Translator | 原生文本翻译 | 填写资源密钥；区域资源还需填写 Azure 区域标识 |
| 阿里云 Qwen-MT | 专用机器翻译协议 | 默认 `qwen-mt-turbo`；以账号实际可用模型为准 |

DeepL 和 Azure Translator 按批提交段落，并校验返回数量与原文顺序。Qwen-MT 每段请求使用专用翻译参数，最多三个并发请求；文字区域较多时，其延迟取决于段落数量和服务限流。专用服务始终翻译全部输入，不执行通用大模型的自定义提示词；DeepL 可使用最近原文作为上下文，Azure 和 Qwen-MT 当前不提交历史上下文。

网络设置提供 **系统代理、直接连接、自定义 HTTP 代理**。自定义代理填写 `主机:端口`，通过 HTTP CONNECT 承载 HTTPS；不支持 SOCKS 或代理账号密码。主连接、视觉连接、模型列表共用网络设置。连接复用不跨越不同主机或代理配置；请求具有总时限与取消机制，禁止自动重定向，不关闭 TLS 证书验证。原生服务对短暂限流或网关错误最多重试一次，且受总时限约束；较长的 Retry-After 返回错误而不持续等待。

**完整翻译所有已识别文字** 默认开启。OCR 模式逐个核对识别文字的区域编号，缺失时最多补译一次，已完成译文予以保留，仍缺失则报告错误。AI 模式要求翻译全部可见文字，完整性取决于模型。完整响应不增加复核请求；按自定义要求只翻译部分内容时可关闭此项。

## 模型请求参数

大模型请求默认关闭思考。主连接和独立视觉连接分别提供 **请求参数（JSON）** 编辑区，参数随服务连接保存；切换服务后恢复对应草稿。留空或填写 `{}` 使用默认关闭配置。仅支持思考的模型可能拒绝关闭参数，此时需更换模型或手动指定其支持的配置，不自动采用服务默认值。

编辑区填写 API 请求体字段，而非提示词或 SDK 的 `extra_body` 包装。对象逐层合并，显式字段优先；`null` 删除对应默认字段。模型、消息内容、流式开关及 JSON 响应格式由程序管理。**格式化并校验 JSON** 检查语法；字段是否受支持由服务端校验。密钥仍填写在 API 密钥栏。参数适用于大模型翻译与连接自检，不用于模型列表、DeepL、Azure Translator 或 Qwen-MT。

例如，DeepSeek 开启思考并设为高强度：

```json
{
  "thinking": {"type": "enabled"},
  "reasoning_effort": "high"
}
```

其他接口使用各自的官方字段：OpenAI Chat Completions 使用 `reasoning_effort`；千问混合思考模型使用 `enable_thinking`；Claude 使用 `thinking`；Gemini 原生接口使用 `generationConfig.thinkingConfig`。具体取值以所选模型为准。Gemini 3 和 Gemini 2.5 Pro 不将最低思考强度视为关闭，需要用户明确指定支持的配置。

参数定义参见 [OpenAI](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[DeepSeek](https://api-docs.deepseek.com/guides/thinking_mode)、[千问](https://help.aliyun.com/zh/model-studio/deep-thinking)、[Claude](https://platform.claude.com/docs/en/api/messages) 和 [Gemini](https://ai.google.dev/api/generate-content) 官方文档。

## 诊断日志

程序自动记录本地诊断日志。右键托盘图标，选择 **打开诊断日志**；文件位于 `%LOCALAPPDATA%\ScreenAITranslator\logs`，当前文件为 `diagnostic.jsonl`。复现问题后，可提供该文件及同目录的轮转日志用于排查。

日志包含时间、任务编号、OCR 与排版耗时、文字或图片路由及原因、模型名称、请求次数、网络收发阶段、剩余时限、缺失区域编号和错误分类。日志采用 UTF-8 JSON Lines 格式，时间为 UTC；不记录密钥、请求头、接口地址、截图、提示词及原文译文。每个文件最多 2 MiB，保留当前文件及 3 个轮转文件。日志写入失败不阻断翻译。

## 排版与阅读

OCR 模式保留本地原文位置，通过区域编号关联译文。AI 模式使用模型返回的位置。两种模式均将位置换算为截图物理像素，用于原位排版。

自动字号依据字形高度估算，并通过 DirectWrite 测量译文。译文限制在对应段落范围内；内容超出局部范围时，可在蓝色标记处滚动或打开全文阅读。固定字号模式不自动缩小字号。存在重叠冲突的区域保留原图，对应译文可在全文阅读中查看。

启用 **匹配原文文字颜色** 时，程序提取各段落的主文字颜色，尽量保持链接、正文和灰色说明的颜色。每个段落使用一种主色，不复原逐字混合配色。关闭该选项后使用手动颜色；无法可靠提取原色时使用满足对比度要求的回退颜色。字体下拉列表提供常用字体名称，实际使用本机已安装字体，缺失字体由系统替代。

默认情况下，结果持续显示。启用自动隐藏后，拖动期间暂停隐藏。关闭原位覆盖后使用选区译文框。点击正文不会关闭结果，也不会将点击传递到下方窗口。

排版和背景处理主要适用于水平文字及纯色背景。复杂背景、严重偏离的模型坐标和识别错误可能影响覆盖效果；程序不提供复杂背景的生成式修复。

## 区域移动与复用

鼠标移到翻译框边缘，出现移动光标后按住左键拖动。拖动期间仅显示边框，框内透明；松手后按原截图尺寸截取新位置并翻译。移动范围限制在当前显示器内。右键取消或拖动中断时恢复原位置与内容；单击、轻微抖动或拖回原位不触发重译。

**翻译上次区域** 使用本次运行最后一次提交的选区。普通框选完成或边框拖动松手后均会更新该区域；取消框选或取消拖动不会替换已有区域。提交后的翻译即使失败或被取消，仍保留该位置以便重试。全文阅读窗口的尺寸不改变重译所用的原截图尺寸。

选区仅保存在内存中，退出程序后清空。尚无选区时，执行翻译上次区域会进入手动框选。关闭译文或设置窗口不会退出托盘程序；区域复用不执行自动轮询。

## 数据与模型服务

纯文本翻译会将识别文字发送给用户配置的服务，不上传截图；AI 识图翻译会发送所选区域的截图，不运行或提交本地 OCR。通用模型启用上下文时还会发送相关历史原文和译文。主连接与视觉连接的 API Key 均使用 Windows DPAPI 加密保存在本机；服务的计费、数据处理和可用性由对应提供方决定。
