# 你给我翻译翻译什么叫翻译

Windows 原生翻译工具，提供会话式文本与图片翻译，以及屏幕区域翻译。界面采用 WinUI 3。

## 主要功能

- **文本翻译**：输入文字、添加图片或混合发送，按所选目标语言返回纯文本译文。支持简体中文、英语、日语、韩语、繁体中文、法语、德语和西班牙语。
- **图片输入**：支持文件选择、剪贴板粘贴和文件拖入。每次最多四张图片，单张文件上限为 20 MB；多帧图片读取第一帧。
- **截图翻译**：选择本地 OCR 文字翻译或 AI 识图翻译，将屏幕区域翻译为简体中文。支持原位覆盖、原图与全文阅读、复制译文、拖动重译和复用上次区域。
- **共用连接**：支持 OpenAI Compatible、DeepSeek、Gemini、Claude 及常见平台，也支持 DeepL、Azure Translator 和 Qwen-MT 专用文本翻译协议。不同服务分别保存连接配置。
- **操作与显示设置**：提供开机启动、托盘、全局快捷键和截图译文字体、字号、颜色及背景设置。编辑快捷键时暂停全部全局快捷键。

## 运行条件

适用于 Windows 10 1809 及以上版本的 x64 系统。翻译需要网络连接和用户提供的 API 密钥。图片输入与 AI 识图翻译需要支持图片的模型；DeepL、Azure Translator 和 Qwen-MT 仅支持文字。

从 [GitHub Releases](https://github.com/DS-BigMountain/ScreenAITranslator/releases/latest) 下载安装包或便携包。便携版完整解压后运行 `你给我翻译翻译什么叫翻译.exe`。程序需与配套运行时、图标、`models` 目录和许可证共同使用，无需另行安装 Python 或 GPU 环境。

## 使用方法

1. 打开 **设置 → 模型连接**，选择服务并填写地址、密钥和模型名称。DeepL 与 Azure Translator 无需选择模型；Azure 区域资源还需填写区域。保存后，两种翻译页面共用该连接。
2. 在 **文本翻译** 中选择目标语言，输入文字或添加图片后发送。默认 Enter 发送、Shift+Enter 换行；可在常规设置中改为 Ctrl+Enter 发送。回复仅包含译文，支持复制、停止、重试与清空会话。
3. 在 **截图翻译** 中选择翻译模式。OCR 模式在本地识别英语、日语或韩语后仅上传文字；AI 模式直接上传所选区域图片。点击 **框选翻译** 或使用自行设置的快捷键开始。
4. 框选时按 Esc 或右键取消。译文工具条可切换原位译文、原图和全文阅读；拖动边框后按新区域重新翻译。
5. 在 **设置 → 常规** 配置启动、托盘与快捷键，在 **显示效果** 调整截图译文样式。修改设置后点击 **保存设置**。

**测试 API** 使用内置样本验证当前截图模式的连接，不截取桌面，可能产生计费请求。图片识别与翻译质量取决于所选服务和模型，获取模型列表不代表模型支持图片。

配置保存在 `%LOCALAPPDATA%\ScreenAITranslator`，密钥通过 Windows 用户凭据保护。网络支持系统代理、直连和自定义 HTTP 代理；高级设置提供请求时限与 JSON 请求参数。通用大模型默认关闭思考，具体参数须符合服务端定义。

文本会话与截图上下文分别在内存中管理，不写入磁盘；关闭主窗口后程序继续在后台运行，重新打开可继续当前会话，退出程序后清除。截图翻译上次区域仅在本次运行中保留。诊断日志不记录密钥、截图或原文译文。
