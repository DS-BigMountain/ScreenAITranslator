# 屏幕翻译 · Screen AI Translator

Windows 原生屏幕翻译工具。框选屏幕区域后，程序识别原文位置并调用用户配置的模型生成译文，在原位置覆盖显示。识别结果可靠时采用纯文本翻译，否则使用视觉模型识别并翻译。设置界面采用 WinUI 3，截图和透明覆盖层采用 Win32 / Direct2D。

## 主要功能

- **框选翻译**：拖动选择屏幕区域，松手后立即显示选区边框和翻译状态，直至译文显示；处理期间可以取消。
- **原位覆盖**：依据文字行和段落位置排版，自动估算字号并匹配原文主文字颜色。
- **多种阅读方式**：在原位译文、原始截图和全文阅读之间切换，支持复制译文；切换视图无需再次请求模型。
- **拖动重译**：拖动译文框边缘调整位置，松手后截取新区域并翻译。
- **翻译上次区域**：复用本次运行最后一次提交的选区，适用于固定位置的字幕、对话框和页面内容。
- **显示与操作设置**：支持常用字体下拉选择、自定义已安装字体、固定或自动字号、手动文字颜色、背景透明度、自动隐藏及自定义快捷键。

## 运行条件与下载

适用于 Windows 10 1809 及以上版本的 x64 系统。翻译需要网络连接和用户提供的 API Key。通用大模型需支持本程序的 JSON 返回协议；专用翻译服务使用各自的原生协议。OCR 失败时的图片兜底需要另行选择支持图片输入的模型。

从 [GitHub Releases](https://github.com/DS-BigMountain/ScreenAITranslator/releases/latest) 下载安装包或便携包。安装版提供简体中文安装向导；便携版完整解压后运行 `ScreenAITranslator.exe`。

资源包包含 WinUI 3 运行时、ONNX Runtime、本地 OCR 模型、图标文件及第三方许可证，不需要另外安装 Python、PaddlePaddle 或 GPU 环境。程序必须与配套运行时、图标文件及 `models` 目录共同使用，不能只复制主程序 EXE。

## 使用流程

1. 打开 **模型连接**，选择服务，填写 API 地址、密钥和账号可用的模型名或部署 ID。模型名可以手动输入，也可以获取列表；DeepL 和 Azure Translator 无需选择模型。同一服务切换模型保留密钥；不同服务分别保存连接配置，切回时恢复地址、模型和密钥。首次选择未配置服务时，其密钥为空。主连接和视觉连接分别管理，点击保存设置后写入磁盘；未保存即关闭窗口会放弃本次修改。
2. 按需配置独立视觉连接和网络代理，点击 **测试连接**。自检验证主连接文字翻译，并在启用独立视觉连接时验证图片输入；不上传桌面截图，可能产生多次计费请求。模型列表不保证视觉能力，小样本自检不代表复杂页面翻译质量。
3. 保存设置，在 **翻译与偏好** 中点击 **框选翻译**，或使用自行设置的快捷键。
4. 拖动框选，松开鼠标开始翻译。Esc 或右键取消框选；处理期间点击状态框的 × 取消。
5. 使用选区旁的工具条切换 **原位译文 / 查看原图 / 全文阅读**，或执行 **复制译文 / 重新框选 / 关闭**。

## 语言与识别模式

原文语言下拉框提供自动识别、英语、日语和韩语，译文仍为中文。程序内置 PP-OCRv5 文字检测模型、通用识别模型、英文专用模型和韩语模型，无需安装 Windows OCR 语言包。手动选择语言时，本地 OCR 提供原文及位置；所有文字区域的识别置信度均达到 0.85 时，仅将文字发送给模型，模型返回区域 ID 和译文，原文与坐标由程序保留。置信度仅用于路径选择，不等同于识别准确率。

OCR 按次加载模型，检测与识别分阶段使用内存；识别完成、取消或失败后释放模型会话和推理缓冲区。该方式减少处理期间和空闲时的内存占用，但每次翻译包含模型加载耗时。后台启动时按需初始化设置界面；截图、原位译文和全文阅读仍保留原有功能。

设置窗口、选区和译文全部关闭且后台任务完成约 5 秒后，程序切换到干净的后台进程，释放已加载的界面与识别运行时。后台保留托盘、快捷键、配置、上次选区及未过期的翻译上下文。会话内容通过仅供子进程继承的匿名内存传递，不写入临时文件；上下文的原有过期时间保持不变。下次打开设置或翻译时重新加载所需组件。交接失败时保留原进程。仅隐藏但未关闭的设置窗口仍保留编辑草稿，不进入该收缩流程。

| 模式 | 适用内容 | 处理方式 |
| --- | --- | --- |
| 自动识别 | 未知语言、其他语言或混合语种 | 本地仅检测文字位置，视觉模型判断语种、识别并翻译 |
| 英语 | 以英文为主 | 使用英文专用识别模型 |
| 日语 | 以日文为主 | 使用通用识别模型 |
| 韩语 | 以韩文为主 | 使用韩语识别模型，可同时识别英文及数字 |

自动识别直接走图片翻译路径，不额外发起语言分类请求，也不依次加载各语种识别模型。它需要可用的视觉连接；仅配置专用文字翻译服务时，应选择明确的原文语言，或补充独立视觉连接。其他语种及漫画竖排、艺术字体的识别效果取决于视觉模型，不能保证任意语言或版式均能准确识别。

存在低置信度文字时，程序将图片及识别结果一并提交给视觉模型校正和翻译。本地识别不可用或存在未能识别的检测框时，程序尝试保留文字检测框、行高和区域 ID，再由视觉模型识别内容；检测也不可用时使用模型返回的位置，并进行像素边界和字号校正。每次请求只加载所需模型，完成后释放；推理阶段可取消，设有 15 秒时限。

默认使用主连接。启用 **OCR 不可靠时使用独立视觉连接** 后，程序在图片路径切换至该连接，并使用其独立密钥。专用翻译服务无法接收图片，未配置视觉连接时会明确提示。完成状态显示本次翻译路径、OCR 耗时、API 耗时、请求次数及总处理时间；API 耗时包含网络传输、模型响应、解析及重试。

## 服务连接与网络

| 服务 | 接入方式 | 配置要点 |
| --- | --- | --- |
| DeepSeek、OpenAI、自定义 OpenAI Compatible | Chat Completions | 填写账号可用的模型名称；视觉能力取决于具体模型 |
| 阿里云百炼、火山方舟、Moonshot、智谱、硅基流动 | 各平台兼容接口 | 预设官方地址；部署型接口需填写部署 ID；区域地址可自行调整 |
| Google Gemini | 原生 generateContent | 使用 Gemini API 密钥和模型名称 |
| Anthropic Claude | 原生 Messages | 使用 Anthropic API 密钥和模型名称 |
| DeepL | 原生文本翻译 | Free 默认使用 `https://api-free.deepl.com/v2`；Pro 使用 `https://api.deepl.com/v2` |
| Microsoft Azure Translator | 原生文本翻译 | 填写资源密钥；区域资源还需填写 Azure 区域标识 |
| 阿里云 Qwen-MT | 专用机器翻译协议 | 默认 `qwen-mt-turbo`；以账号实际可用模型为准 |

DeepL 和 Azure Translator 按批提交段落，并校验返回数量与原文顺序。Qwen-MT 每段请求使用专用翻译参数，最多三个并发请求；文字区域较多时，其延迟取决于段落数量和服务限流。专用服务始终翻译全部输入，不执行通用大模型的自定义提示词；DeepL 可使用最近原文作为上下文，Azure 和 Qwen-MT 当前不提交历史上下文。

网络设置提供 **系统代理、直接连接、自定义 HTTP 代理**。自定义代理填写 `主机:端口`，通过 HTTP CONNECT 承载 HTTPS；不支持 SOCKS 或代理账号密码。主连接、视觉连接、模型列表共用网络设置。连接复用不跨越不同主机或代理配置；请求具有总时限与取消机制，禁止自动重定向，不关闭 TLS 证书验证。原生服务对短暂限流或网关错误最多重试一次，且受总时限约束；较长的 Retry-After 返回错误而不持续等待。

**完整翻译所有已识别文字** 默认开启。通用模型漏返非空原文区域时自动重试一次，仍缺失则报告错误。需要按自定义提示词只翻译部分内容时可关闭此项。该校验不能发现 OCR 本身完全没有检测到的文字。

## 排版与阅读

原位译文以截图物理像素为坐标依据，通过文字行间距、对齐关系和分隔线组织段落。段落使用固定 ID 关联译文，避免响应顺序改变导致位置错配。

自动字号依据字形高度估算，并通过 DirectWrite 测量译文。译文限制在对应段落范围内；内容超出局部范围时，可在蓝色标记处滚动或打开全文阅读。固定字号模式不自动缩小字号。存在重叠冲突的区域保留原图，对应译文可在全文阅读中查看。

启用 **匹配原文文字颜色** 时，程序提取各段落的主文字颜色，尽量保持链接、正文和灰色说明的颜色。每个段落使用一种主色，不复原逐字混合配色。关闭该选项后使用手动颜色；无法可靠提取原色时使用满足对比度要求的回退颜色。字体下拉列表提供常用字体名称，实际使用本机已安装字体，缺失字体由系统替代。

默认情况下，结果持续显示。启用自动隐藏后，拖动期间暂停隐藏。关闭原位覆盖后使用选区译文框。点击正文不会关闭结果，也不会将点击传递到下方窗口。

排版和背景处理主要适用于水平文字及纯色背景。复杂背景、严重偏离的模型坐标和识别错误可能影响覆盖效果；程序不提供复杂背景的生成式修复。

## 区域移动与复用

鼠标移到翻译框边缘，出现移动光标后按住左键拖动。拖动期间仅显示边框，框内透明；松手后按原截图尺寸截取新位置并翻译。移动范围限制在当前显示器内。右键取消或拖动中断时恢复原位置与内容；单击、轻微抖动或拖回原位不触发重译。

**翻译上次区域** 使用本次运行最后一次提交的选区。普通框选完成或边框拖动松手后均会更新该区域；取消框选或取消拖动不会替换已有区域。提交后的翻译即使失败或被取消，仍保留该位置以便重试。全文阅读窗口的尺寸不改变重译所用的原截图尺寸。

选区仅保存在内存中，退出程序后清空。尚无选区时，执行翻译上次区域会进入手动框选。关闭译文或设置窗口不会退出托盘程序；区域复用不执行自动轮询。

## 数据与模型服务

纯文本翻译会将识别文字发送给用户配置的服务，不上传截图；视觉翻译会发送所选区域的截图及可用识别结果。通用模型启用上下文时还会发送相关历史原文和译文。主连接与视觉连接的 API Key 均使用 Windows DPAPI 加密保存在本机；服务的计费、数据处理和可用性由对应提供方决定。
